 CreatorMatch 
 Connecting Brands with Micro-Creators
 About: CreatorMatch is a website that connects brands with micro-creators for collaboration.
 Problem: Brands find it difficult to find suitable creators, and creators struggle to find brands.
 Solution: Our website makes it easier for brands and creators to discover and connect with each other.
 Features:  Separate registration and login for brands and creators, profile creation, and profile viewing.
 Creator Discovery: Brands can search for creators based on location and niche.
 Communication:  Brands can save creator profiles and communicate with creators through messages.
 Technologies Used:  HTML, CSS, JavaScript and LocalStorage.
 Future Scope: Add AI-based matching, engagement analytics and campaign management.
